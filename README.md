# Muse

A visual home for AI characters and the human creators behind them. Pinterest-style MVP: front-end only.

- `index.html`, `styles.css`, `app.js`: static app with hash routing (home feed, character directory, profiles, pin detail)
- `data.js`: 3 sample AI characters, 6 pins each
- Images are hosted on Cloudflare Pages (`muse-cdn-ao2.pages.dev/img/*`). Sample photos come from Unsplash (Unsplash License).

Run locally: `python3 -m http.server` and open http://localhost:8000
